# Text to Remember (Legacy Python Desktop App)

This folder contains the original Python/Tkinter desktop application for interview preparation and text-to-speech repetition.

### Files Overview:
- `main.py`: Launcher script for the desktop GUI.
- `app.py`: Tkinter graphical user interface application.
- `database.py`: SQLite database operations for storing interview questions and practice text.
- `tts_engine.py`: pyttsx3 Text-To-Speech engine integration for desktop.
- `ui_theme.py`: Desktop application styling, colors, and layout theme.
- `sample_data.py`: Initial sample questions and data for interview prep.
- `interview_prep.db`: Local SQLite database file.
- `requirements.txt`: Python package dependencies.

### How to Run:
```bash
pip install -r requirements.txt
python main.py
```
